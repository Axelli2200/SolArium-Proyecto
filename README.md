# ☀️ SolArium - Sitio Web Oficial
Este proyecto corresponde al **Trabajo Final** de la asignatura, desarrollado por **Víctor Obopol**. 

Consiste en el diseño y desarrollo de un sitio web completo, responsivo y optimizado para el proyecto "SolArium".

## 🚀 Enlaces del Proyecto

* **Repositorio en GitHub:** [👉 Código Fuente](https://github.com/Axelli2200/SolArium-Proyecto)
* **Sitio Web en producción (GitHub Pages):** [👉 Visitar la Web](https://axelli2200.github.io/SolArium-Proyecto/)

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio web.
* **CSS3:** Diseño, estilos visuales y maquetación adaptada a dispositivos móviles.

## 📂 Estructura del Repositorio

* `/index.html` - Página principal de acceso al sitio web.
* `/styles.css/` - Carpeta con los estilos del sitio.
* `/imagenes/` - Recursos gráficos.
* `/Videos/` - Archivos multimedia.
* `/Views/` - Páginas secundarias de la web.
* `README.md` - Documentación (este archivo).
